ossia::net::hid_device Class Reference

Detailed Description

A HID device opened for reading and writing reports.

Input reports are delivered on a dedicated thread. write(), send_feature_report() and get_feature_report() are synchronous and may be called from any thread.

Output and feature report buffers start with the report id, 0 for devices without numbered reports. Input reports start with the report id only when the device uses numbered reports.
