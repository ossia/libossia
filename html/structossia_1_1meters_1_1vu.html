ossia::meters::vu Struct Reference

Detailed Description

VU meter (IEC 60268-17): full-wave average through a second-order system that reaches 99% of a steady tone in 300 ms with a 1.25% overshoot (the standard allows 1 to 1.5%). Scaled so that a sine reads its RMS value; 0 VU is wherever the reference level puts it.
