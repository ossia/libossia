ossia::midi_note_tracker Struct Reference

Detailed Description

The notes a MIDI stream has started and not yet stopped.

Whoever cuts a stream short (a cable taken off, a node removed, an output rebound to another device) asks for what is left sounding and stops it at the far end, which otherwise never gets the note off.

One bit per (channel, pitch): a note on sets it, a note off clears it, so tracking a message is a mask and a store, and nothing is ever allocated. Releasing is conservative on purpose: a note off for a note that does not sound is ignored by receivers, a missing one is a note that never ends. Hence

  • a bit, not a count: two note ons for one pitch are stopped by one note off, the way MIDI 1 receivers take them;
  • the UMP groups are not part of the key: the notes are stopped on every group that carried a note on while some were held, almost always one;
  • "all notes off" and "reset all controllers" do not clear anything, since not every receiver honours them.

Tracking keeps no summary of the table up to date: that would be paid on every message, for the sake of a release that happens once.

The damper pedal is tracked along: notes released under a pedal that stays down ring forever just as well.
