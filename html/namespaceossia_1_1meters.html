ossia::meters Namespace Reference

Detailed Description

Level meter ballistics: what a meter needle or bar shows for a signal, per the standards that define each kind of meter.

Each follower takes blocks of samples and holds a linear level, scaled so that a steady sine of amplitude A reads A (except the RMS follower, which reads the RMS value unless asked for AES-17 sine referencing). Nothing allocates after prepare().
