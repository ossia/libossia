ossia::meters::ppm Struct Reference

Detailed Description

Quasi-peak programme meter (IEC 60268-10).

The rise follows the signal's rectified value through a one-pole charge whose speed is set so that a 5 kHz tone burst lasting the integration time reads 2 dB below the same tone held steady; the fall is exponential at the standard's rate. Type I (DIN, Nordic): 5 ms, 20 dB in 1.5 s. Type II (BBC, EBU): 10 ms, 24 dB in 2.8 s.
