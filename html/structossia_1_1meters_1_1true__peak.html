ossia::meters::true_peak Struct Reference

Detailed Description

True peak (ITU-R BS.1770 Annex 2): the peak of the signal oversampled 4 times below 96 kHz, twice below 192 kHz, with a 48-tap windowed-sinc polyphase interpolator; at 192 kHz and above, the sample peak. Holds the highest absolute value of the last process() call in block_peak.
