Detailed Description

Generic HID device.

Where the report descriptor can be read, each input and output usage gets a parameter under /input and /output. Raw reports are always available under /raw:

  • /raw/input: every input report, as a list of bytes (report id first when the device numbers its reports)
  • /raw/output: a list of bytes, report id first, written as an output report
  • /raw/feature/send: a list of bytes, report id first, sent as a feature report
  • /raw/feature/get: a report id; the report read back lands in /raw/feature/value

bool ossia::net::hid_protocol::observe ( ossia::net::parameter_base & ,
bool  )
overridevirtual

Notify the network that a parameter should be listened to.

In some protocols (Minuit, OSCQuery), this may send a message to the other client so that it regularly sends values of this parameter to the local computer.

If a parameter is listened to, when a message is received, parameter_base::setValue will be called, which will notify the local signals. Else, parameter_base::setValueQuiet will be called : the value will be updated but the signals won't be notified.
